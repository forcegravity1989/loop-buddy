这个目录放原型与设计相关的产物:Open Design 导出的文件、界面设计稿、架
构或数据设计文档等。不强制规定子目录结构,按项目实际需要组织即可。

## 写作约定

每篇设计文档开头都要有一段 30 秒导读,说清楚三件事:这篇文档是什么、给
谁看、现在还作数吗。读者(人或 agent)打开一份陌生文档,应该在读正文之
前就知道要不要认真往下读。

设计随项目演进,文档写完就落后是正常状况——过时的文档**不删除**,而是
在顶部加一条横幅注明「历史档案,现状以 XX 为准」,并指向真正当前的那份
文档。删除会让引用过它的旧 commit、旧讨论找不到线索;保留 + 标注既不会
误导人,又留得住决策当时的背景。
