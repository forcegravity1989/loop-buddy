# 适配模块 · 项目群

## 借自哪个项目 / 文件

- 待拍-26 的工厂模式结论(见 `docs/v4-prototype/mvp-blueprint-draft.md`)。
- 提供方今天两位:内部 WeLink(同事实现中)、外部待定。

## 借了什么

- **工厂模式**:一个 trait 两个函数(发一条 / 拉一段历史),换提供方只加一个
  实现,不改调用方。
- 「没配群」是一个**正常的实现**,不是错误分支 —— 未配群的项目发送调用被跳过,
  流程照常走完。

## 没借什么

- **不做发送去重账本**。第六轮草案给它设计过一张表,第七轮盘点判定过不了
  「没人取的不存」这条门槛:重发一条能忍,建一张表来防它不值。
- 不把群历史原文存进库或仓。拉历史只生成一份本机摘要文件,用完即弃。
- 不做登录。WeLink 的登录态由用户自己在本机登好,buddy 只探活。
