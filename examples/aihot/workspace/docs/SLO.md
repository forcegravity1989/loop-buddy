# SLO(诚实可测的质量红线)

每条红线当场真实测量当前值(2026-07-20),不是拍脑袋定的目标。

| 红线 | 当前真实值 | 判定方式 |
|---|---|---|
| 坏输入必须友好报错,绝不 panic | 未测(见 #17 破坏性测试) | 逐个坏输入真实执行,记录行为 |
| `python3 -m unittest discover tests` 全绿 | 19/19 通过,0.007s | 真实运行 |
| 单次生成耗时 | 49.7s(HN fetch 主导) | `time python3 -m aihot.main` |
| `cargo`/`pip` 依赖数 | 0(stdlib-only) | `grep -r "^import\|^from" aihot/` 人工核对无第三方包 |
| 单源不可达时,另一源仍能出日报 | 未测(见 #17) | 断网单源模拟 |
| 空关键词配置不崩溃但也不假装有内容 | 已在 filter.py 单测覆盖(`test_empty_keywords_excludes_everything`) | 单测 |

「单次生成耗时」定的不是硬性阈值(依赖 HN API 真实响应速度,不受本项目控制),
而是**每次真实测量并入账**——如果哪天涨到 3 分钟以上,才是真正值得开新一轮
优化的信号,不是提前拍一个数字装样子。
