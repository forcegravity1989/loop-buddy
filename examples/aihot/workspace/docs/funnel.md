# 新用户漏斗走查 · 2026-07-20

以从未见过这个项目的人视角,只看 README.md,真实执行「发现 → 安装 → 首次使用 → 再次使用」。

## 发现 → 首次使用

真实执行 `python3 -m aihot.main`:零摩擦,零依赖安装,退出码 0,28 条真实日报生成。
`python3 -m http.server -d digests 8765` 后 `curl` 真实请求 index.html 与当日 `.md`
文件均 200——README 的两条命令都真实可用,不是文档过时。

## 真实摩擦点(不臆想,只记录真遇到的)

1. **digests/*.md 通过 http.server 打开是未渲染的纯文本**——index.html 本身有样式,
   点进具体一篇日报后浏览器只显示原始 Markdown 语法(`**粗体**`、`[链接](url)` 字面量),
   不是渲染后的页面。对定位为「web 应用」的产品,这是真实的体验落差——用户点开
   `index.html` 期待"网页",点进一篇具体日报却看见 markdown 源码。
2. **README 没写 Python 版本要求**——本机验证用的是 3.9.6,`str.removesuffix`(render.py
   用到)是 3.9+ 特性,3.8 及更早会真实报错;README 没提前说清楚。

## 结论

摩擦点 1 是真实的、影响体验的,值得作为下一件实验(#14);摩擦点 2 较小,一并在
README 补一行版本要求,不单独开活。
