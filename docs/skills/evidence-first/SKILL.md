# 证据先行 (evidence-first)

## 何时用

原型段整理证据与调研文档时;以及任何要在产出里引用事实、数字、竞品
情况的时刻——包括你觉得「这个我知道」的时刻。

## 步骤

1. 只记录两类内容:(a) 你直接验证过的事实(真实命令输出、真实文件内容);(b) 你的先验知识——必须标注「未核实」。
2. 每条证据注明来源:文件路径、命令、或「知识截止内记忆,未核实」。
3. 禁止编造统计数字与引用;没有可靠数字就写「无可靠数字」。
4. 结论按「证据 → 洞察 → 假设」链书写,断链处如实标断。

## 反例

「该领域约 70% 的团队存在此问题」——没有来源、也没标未核实,这是幻觉
冒充事实,比留白更糟。
